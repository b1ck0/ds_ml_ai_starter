Read top to bottom: a request enters through FastAPI (the only piece a Java backend engineer
has built dozens of times already), gets handed to the ADK runtime, which decides -- per turn --
whether it needs a tool (goes out over MCP to a FastMCP server wrapping some real system) or a
memory lookup (goes to pgvector for a nearest-neighbour search over embeddings) before it ever
calls the LLM provider itself. The LLM call is the one arrow in this whole diagram that is
key-gated; every other arrow runs locally, for free, with nothing but this chapter's Docker
container and Python environments.
