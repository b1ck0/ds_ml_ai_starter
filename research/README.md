# research/

Grounding notes produced by the **Haiku researcher** (`.claude/agents/researcher.md`). One
`NOTE-<n>-<slug>.md` per verified question: the answer, the source URL, the date checked, caveats,
and a recommendation for the chapter writer.

No chapter asserts an external fact (a package version, a dataset URL, a library API, a metric
formula) that isn't grounded in a NOTE here or an inline citation. See `.claude/skills/research-brief`.
