# NOTE-14: Data Science theory definitions — L1/L2 regularization, bias–variance, bagging vs boosting (2026-09-02)

**Answer:** L1 regularization penalizes absolute coefficient magnitudes and produces sparse solutions (coefficients → 0); L2 regularization penalizes squared magnitudes and shrinks all coefficients uniformly without zeroing. Bias–variance decomposition: E[error] = Bias² + Variance + irreducible error; models with high bias underfit, high variance overfit. Bagging reduces variance by training independent models on bootstrap samples and averaging; boosting reduces bias by training models sequentially on previous errors. All definitions verified against authoritative sources 2026-09-02.

**Caveats / limits:**

- **L1 vs L2 intuition:** The difference in penalty geometry is crucial: L1 has "corners" (piecewise linear), leading to solutions on axes (sparse); L2 is smooth (quadratic), leading to proportional shrinkage. Both are convex; the choice depends on the problem (feature count, interpretability, multicollinearity tolerance).
- **Sparsity:** L1 produces exactly zero coefficients when the penalty term is large; L2 produces arbitrarily small but non-zero coefficients. This makes L1 inherently more interpretable for feature selection, but L2 is more numerically stable in some contexts.
- **Regularization parameter (λ/alpha):** Both L1 and L2 require tuning via cross-validation. λ=0 → no regularization (classical regression); λ→∞ → all coefficients → 0. The optimal λ is problem-dependent and data-dependent.
- **Bias–variance tradeoff:** The decomposition assumes a fixed true model; in practice, the irreducible error term is unknown. Visual inspection (learning curves plotting train/test error vs. model complexity) helps diagnose whether a model is under- or over-fitting.
- **Bagging limitations:** Assumes independence of base learners (each trained on different bootstrap samples); works best with unstable, high-variance models (e.g., decision trees). Does not reduce bias—may even increase it slightly on already-biased weak learners. Random Forest is a successful bagging variant.
- **Boosting limitations:** Sequential training is computationally expensive (cannot parallelize easily); sensitive to hyperparameters (learning rate, base learner depth) and outliers/noisy labels. Can overfit if iterations are not controlled. AdaBoost, Gradient Boosting, XGBoost are common instantiations.
- **Bagging vs boosting trade-off:** Bagging is more robust and easier to parallelize; boosting is more powerful on complex/structured data but requires careful tuning. Modern practice often prefers boosting for tabular data, bagging for image/text.
